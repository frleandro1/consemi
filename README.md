# CONSEMI

Site institucional do Conselho Missionário da Igreja Batista da Filadélfia de Canoas.

## Páginas

- `index.html`: apresentação do CONSEMI, áreas de atuação, parceiros e formas de contribuição.
- `projeto-alcance.html`: página da campanha Projeto Alcance.
- `parcerias.html`: descrições das oito parcerias missionárias, imagens e vídeos organizados por projeto.

## Estrutura

- `style.css`: estilos responsivos compartilhados pelas páginas.
- `script.js`: menu de navegação para telas menores.
- `imagens/`: mapa, retratos e imagens institucionais.
- `projeto alcance/`: imagens da campanha Projeto Alcance.
- `midias/`: imagens e vídeos renomeados das publicações e atividades das parcerias missionárias.

## Como visualizar

Abra `index.html` diretamente no navegador. Não há dependências de servidor, banco de dados ou processo de compilação.

Para testar a navegação entre páginas e o menu mobile, use um servidor local simples ou a abertura direta dos arquivos no navegador.
